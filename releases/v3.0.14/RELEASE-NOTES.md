# MLDDS 3.0.14

Release estável do MLDDS Automation.

## Principais novidades

- Rede MLDDS de conhecimento coletivo;
- Global Knowledge Sync entre instalações;
- Global Routing Memory;
- cache local e operação resiliente a indisponibilidade da Cloud;
- outbox persistente;
- Knowledge Assistant conversacional com Llama 3.2 3B;
- CombinedRules estruturados e compartilhados;
- aprendizado coletivo por evidências e conflitos globais;
- Inteligência 3.1, Conhecimento Operacional, Correções Aprendidas e Memória Global;
- melhorias de retomada pós-Save, proteção contra Save duplicado, fail-closed preservado e zero focus stealing;
- correção de captura de cidades e markers na extensão 2.0.10.

## IMPORTANTE — EXTENSÃO 2.0.10

Após atualizar para MLDDS 3.0.14:

1. Abra `chrome://extensions`.
2. Localize a extensão MLDDS.
3. Clique em **Recarregar**.

A automação permanece bloqueada caso a extensão carregada esteja em versão incompatível. A extensão não é recarregada automaticamente.

O Assistente IA permanece consultivo: não executa Apply, Save nem altera o DDS livremente. O Virtual Desktop não faz parte desta homologação.
